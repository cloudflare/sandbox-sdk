# Cloudflare Sandbox Bridge

The supported self-deployed bridge is the template on
[`main`](https://github.com/cloudflare/sandbox-sdk/tree/main/bridge/worker).

Pair that template with matching stable `@cloudflare/sandbox` and
`cloudflare/sandbox` versions. Documentation:
[Sandbox bridge](https://developers.cloudflare.com/sandbox/bridge/).

This branch is not a supported bridge release line. Deploy from `main`.
